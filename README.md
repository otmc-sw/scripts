# 🌿 OTMC Scripts
Where store scripts for managing the OTMC project.

| Script       | Name                | Description                                 |
|--------------|---------------------|---------------------------------------------|
| `build.ps1`  | **Project Builder** | Build frontend and backend projects         |
| `format.ps1` | **Code Formatter**  | Remove comments and optimize code           |
| `push.ps1`   | **Project Pusher**  | Commit and push changes to remote           |
| `run.ps1`    | **Project Runner**  | Run frontend or backend in dev mode         |
| `setup.ps1`  | **Project Setup**   | Install dependencies and setup environment  |
| `tag.ps1`    | **Tag Manager**     | Manage git tags and branches                |
| `test.ps1`   | **Test Runner**     | Run Playwright tests                        |
| `upgrade.ps1`| **Project Upgrader**| Upgrade dependencies for both projects      |
